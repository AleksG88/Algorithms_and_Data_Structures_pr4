# Астероиды: поиск столкновений с помощью квадродерева

Практическая работа № 4 "Квадродеревья, октодеревья и k-d деревья" по дисциплине Алгоритмы и структуры данных.

Вариант Астероиды.

Выполнил: Грибенщиков Алексей Сергеевич, группа ЗКИ24-17Б.


## Возможности

- Шары случайного размера и скорости летают по полю
- Шары отскакивают от стенок и друг от друга (абсолютно упругий удар, масса шара равна его площади)
- Поиск столкновений через квадродерево, без полного перебора
- Отображение границ квадродерева в реальном времени
- Окно настроек перед запуском: количество шаров, границы радиуса,
  границы скорости, размер поля

## Установка и запуск

Нужен Python 3.10 или новее.

Установить библиотеки:

```
python -m pip install -r requirements.txt
```

Запустить (из корня проекта):

```
python -m game.main
```

## Управление

- **T** — показать или скрыть границы квадродерева
- Закрыть окно — выход

## Как работает поиск столкновений

Самый простой способ — проверять каждый шар с каждым. Но так нельзя:
при 20 шарах это 190 проверок, а при 200 шарах уже почти 20 000,
и так 60 раз в секунду. Компьютер просто не будет успевать.
К тому же шары в разных углах поля всё равно не могут столкнуться,
их и проверять незачем. Проверять нужно только соседей.

Для этого я сделал квадродерево. Работает оно так.
Всё поле — это один большой квадрат. В него можно положить
не больше 4 шаров. Когда прилетает пятый, квадрат делится на 4 части,
и шары расходятся по своим четвертинкам. Если в какой-то четвертинке
опять стало тесно, она тоже делится на 4. И так дальше.
В итоге там, где шаров много, квадраты мелкие, а где пусто — крупные.
Если нарисовать, кто из кого получился, выходит перевёрнутое дерево,
отсюда и название.

Чтобы найти соседей шара, я беру вокруг него рамку и спрашиваю
у дерева, кто в неё попал. Дерево смотрит только в те квадраты,
которые задевают рамку. Если квадрат рамку не задевает, туда
даже не заглядываем — вместе со всеми шарами внутри.
Поэтому каждый шар проверяется всего с двумя-тремя соседями, а не со всеми.

Шары всё время двигаются, поэтому дерево каждый кадр строится заново.

В дереве есть три основные операции:

- `insert(ball)` — положить шар в дерево
- `query(area)` — найти все шары в рамке
- `remove(ball)` — убрать шар из дерева

## Физика столкновения

Шары считаются столкнувшимися, если расстояние между центрами
не больше суммы радиусов. Удар передаётся вдоль линии, соединяющей
центры; лёгкий шар отлетает сильнее, тяжёлый — слабее.
Перед отскоком проверяется, что шары сближаются, иначе
они могли бы «слипнуться».
